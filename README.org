* Solving Tower of Hanoi
** The purpose of this repository
   This repository contains model, view and controller classes for
   solving Tower of Hanoi.

** Installation in VS code
** Alternative installation method
   1. Clone repository.

** Programming your solution
   Class =TOHApp= contains method
   #+begin_src python :exports code
     solve(num_discs, from_peg, to_peg, intermediate)
   #+end_src
   which you need to modify to solve the problems. Method
   =reset_toh()= of this class calls method =solve()= with correct
   parameters for solving the problem, that is, moving all discs from
   peg A to peg C.

   The version of =solve()= in this repository is a feeble attempt to
   solve this problem, and you need to replace it with your own
   version. Still, the feeble version demonstrates the only additional
   method you need to use:
   - method
     #+begin_src python :exports code
       move(from_peg, to_peg)
     #+end_src
     which moves top disc of peg =from_peg= to peg =to_peg=. This may
     throw an exception if the move breaks the rules of Tower of
     Hanoi, but this exception is caught by the program. Possible
     exceptions are printed into console.
